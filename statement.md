# Campus Event Tracker

## Problem Statement

College students may take part in different college events, but it can be difficult to keep track of which events they have participated in. A simple system is needed to record and check student participation in college events.

## Scope

The Campus Event Tracker is a simple Python-based program for recording participation in three college events. The program allows the user to add participation, search for an event, view a participation summary, and reset participation.

The project is designed as a basic console application for learning and demonstrating Python programming concepts.

## Target Users

The main target users are college students who want to keep a simple record of their participation in college events.

## High-Level Features

1. Add participation for an event.
2. Search for an event and check its participation status.
3. View the total number of events and participation summary.
4. Reset participation for an event.
5. Handle invalid event choices and menu choices.





\## Non-Functional Requirements



1\. Usability

The program should be simple and easy for a college student to use through the menu.



2\. Reliability

The program should correctly record, search, summarize, and reset participation without unexpected errors during normal use.



3\. Error Handling

The program should show an appropriate message when the user enters an invalid event or menu choice.



4\. Resource Efficiency

The program should use low system resources because it is a small console-based Python application.



\# Campus Event Tracker



\## Problem Statement

\## Objectives



1\. To create a simple system for recording student participation in college events.



2\. To allow users to search for an event and check their participation status.



3\. To provide a simple summary of the user's event participation.



4\. To allow users to reset their participation status when required.



5\. To practice Python programming concepts such as dictionaries, functions, loops, conditions, and user input.



\## Functional Requirements



1\. The system should allow the user to record participation for an event.



2\. The system should allow the user to search for an event using its event code.



3\. The system should display the name and participation status of a searched event.



4\. The system should calculate and display the total number of events, participated events, and events not participated in.



5\. The system should allow the user to reset the participation status of an event.



6\. The system should display an error message when an invalid event or menu choice is entered.

1\. Usability  

The program should be simple and easy for a college student to use through the menu.

The program should use low system resources because it is a small console-based Python application.
