# Campus Event Tracker

## Overview

Campus Event Tracker is a simple Python-based console application used to record and check participation in college events.

The program contains three fixed events:

- A - Dance Event
- B - Cricket Event
- C - Poem Writing Event

The user can record participation, search for an event, view a participation summary, and reset participation.

## Features

- Add participation for an event
- Search for an event
- View activity summary
- Reset participation
- Handle invalid choices
- Simple menu-based interface

## Technologies Used

- Python
- Python Dictionary
- Functions
- Loops
- Conditional Statements
- User Input

## How to Run

1. Download or copy the project files.
2. Open the project folder.
3. Run the `main.py` file using Python.
4. Select an option from the menu.
5. Follow the instructions shown on the screen.

## Testing

The program was tested using different inputs, including:

- Adding participation for a valid event
- Searching for a valid event
- Viewing the activity summary
- Resetting participation
- Entering an invalid event choice
- Entering an invalid menu choice
